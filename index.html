Key facts

  • Event: Pet Fair Asia 2026 (28th edition) — Shanghai Pet Expo
  • Dates: 19–23 August 2026 · 3 B2B/trade days (19–21) + 2 public days (22–23)
  • Venue: Shanghai New International Expo Centre (SNIEC), 2345 Longyang Rd, Pudong

Before you go — checklist

  • Register/pre-badge on the official Pet Fair Asia site; save the QR badge offline
  • WeChat installed + set up (primary channel for China suppliers); WhatsApp as backup
  • Alipay / WeChat Pay linked to a card for cabs, food, deposits
  • eSIM or roaming + a VPN set up before landing
  • Plenty of your own namecards (bring 2–3× what you think)
  • Phone storage cleared for photos; power bank for long hall days
  • 12306 booked for the HSR legs (Shanghai→Linyi, and the Shandong→Zhengzhou route)
  • This Upload Hub bookmarked on every team member's phone

At the booth — capture routine

  • Namecard → Upload Hub → Log a Supplier → photo the card, add booth #
  • Interesting product → Log a Product → 2–3 photos, MOQ, target price, pick the supplier
  • Rate interest 1–5 while it's fresh so shortlisting back home is fast
  • Ask for: MOQ, FOB price, lead time, customization/OEM, samples — note in the form
  • Spotted a trend? → Log a Trend / Note before you forget

Setup — one-time (≈10 min)

This connects the Upload Hub to your shared database securely. Done once by whoever manages the site; the team just uses the page after that.

A · Create an Airtable access token

  1. Go to airtable.com/create/tokens → Create token.
  2. Scopes: tick data.records:read and data.records:write.
  3. Access: add the Shanghai Pet Expo 2026 base.
  4. Create it and copy the token (starts with pat…) — you only see it once.

B · Deploy the Worker on Cloudflare

  1. Cloudflare dashboard → Workers & Pages → Create → Create Worker. Name it e.g. fraaash-expo.
  2. Click Edit code, delete the sample, paste in the contents of worker.js, then Deploy.
  3. Worker → Settings → Variables and Secrets → add two secrets:
    AIRTABLE_TOKEN = your pat… token
    BASE_ID = appiFmLjs5kj2T84E
  4. (Optional, recommended) add ALLOW_ORIGIN = your page's address (e.g. https://expo.fraaash.com).
  5. Copy the Worker URL (looks like https://fraaash-expo.yourname.workers.dev).

C · Connect the page & host it

  1. Open index.html, find CONFIG near the top, paste the Worker URL into WORKER_URL, save.
  2. Host the page (your DNS is on Cloudflare, so Cloudflare Pages is easiest): Workers & Pages → Create → Pages → upload index.html → add a custom domain like expo.fraaash.com.
  3. Open it, click Log a Supplier — you'll get the form straight away. Done.

Your root fraaash.com stays on Shopify, untouched. If you specifically need the address fraaash.com/shanghaipetexpo instead of a subdomain, that needs a small Cloudflare Worker route in front — ask and I'll provide it.

Photos and namecards are stored as attachments in the shared database. The token lives only inside the Cloudflare Worker — it is never in the web page, so the public page can't be used to read or wipe your data.
